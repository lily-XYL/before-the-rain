原创百合向长篇视觉小说，现有共通线六章、林晚、许见微、周栀与叶澄四条完整个人线（各第七至十章）。22 岁的沈知夏在毕业雨季重逢林晚，与旧书店的伙伴们准备一场告别。第六章可选四位人物的发展方向或暂不恋爱；四条完整个人线各有三种最终结局与秋日尾声；独身群像收束篇《写给自己的信》与秋日结局也已可玩。

## 开始游戏

直接用 Chrome、Edge 或 Firefox 打开 `index.html` 即可。所有素材均在本地，无需安装依赖、联网或注册。也可双击 `启动游戏.bat`。

需要以本地服务运行时，在本目录执行 `python -m http.server 8000 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8000`。文件方式和服务方式使用不同的存档空间，请固定一种方式游玩。
